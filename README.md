Проект FitLife.

Это консолный бот, помогающий людям следить за здоровьем.

Основные задачи:
знакомство с пользователем;
узнает его параметры (вес, рост);
рассчитывает индекс массы теля (ИМТ);
даст рекомендацию по потреблению воды.

Чтобы развернуть локально репозиторий из GitHub, нужно выполнить
команду git clone. Для SSH: git clone git@github.com:stepan-dev96/FitLife.git
После выполнения в выбранной папке появится папка с именем репозитория — это и есть ваш локальный клон.
